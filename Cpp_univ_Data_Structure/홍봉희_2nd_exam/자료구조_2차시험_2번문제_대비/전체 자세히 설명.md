# 미로 탐색 백트래킹 알고리즘 완전 정리

## 1. 백트래킹(Backtracking)이란?

백트래킹은 **미로를 탈출하는 과정에서 막다른 길에 도달했을 때, 이전 위치로 돌아가서 다른 경로를 시도하는 알고리즘**입니다.

쉽게 말해, 길이 막히면 **"아, 이 길은 안 되겠네"** 하고 돌아가서 다른 길을 가보는 것입니다.

### 1.1 실생활 예시

실제 미로에서 길을 찾을 때의 과정:
- 한 방향으로 쭉 가다가 막다른 곳에 도달
- "어? 이 길은 막혔다"고 깨달음
- 이전 갈림길로 돌아감
- 다른 방향을 시도
- 반복

**이것이 바로 백트래킹입니다.**

---

## 2. 백트래킹의 핵심 개념

백트래킹의 **3가지 핵심 요소**:

### 2.1 탐색(Exploration)
현재 위치에서 모든 방향을 시도해본다.

```cpp
while (d < 8) // 8방향 모두 탐색
{
    // 모든 방향을 하나씩 체크
}
```

### 2.2 저장(Saving State)
이전 위치로 돌아갈 수 있도록 스택에 저장한다.

```cpp
temp.x = i;           // 현재 위치의 x 좌표
temp.y = j;           // 현재 위치의 y 좌표
temp.dir = d + 1;     // 다음에 시도할 방향
st.push(temp);        // 스택에 저장 - 나중에 여기로 돌아올 수 있음
```

이렇게 하면 새로운 위치로 이동한 후, 그 위치에서 모든 방향이 막혀있으면 자동으로 이 위치로 다시 돌아올 수 있습니다.

### 2.3 철회(Backtrack)
길이 없으면 방문 표시를 제거하고 이전 위치로 돌아간다.

```cpp
mark[i][j] = 0;  // 방문 표시 제거 = 이 길은 막혔다는 신호
maze[i][j] = 0;  // 미로에서도 초기화
// while 루프가 끝나면 자동으로 스택에서 이전 위치를 꺼냄
```

## 3. 첫 번째 코드 상세 분석

```cpp
void findPath(int m, int p) {
    try {
        // 시작점 (1, 1) 설정
        mark[1][1] = 1;
        std::stack<items> st;

        // 시작 위치 정보(temp)를 생성하고 스택에 Push
        items temp;
        temp.x = 1;     // 시작 x 좌표
        temp.y = 1;     // 시작 y 좌표
        temp.dir = E;   // 시작 탐색 방향 (East)
        st.push(temp);

        // 스택이 비어있지 않은 동안 계속 탐색
        while (!st.empty())
        {
            // 스택에서 현재 위치 정보를 가져옴 (unstack)
            temp = st.top();
            st.pop();
            int i = temp.x;
            int j = temp.y;
            int d = temp.dir;
            
            // 백트래킹을 위해 현재 위치의 마크와 미로 값을 초기화
            mark[i][j] = 0;
            maze[i][j] = 0;

            // 현재 방향(d)부터 8방향 모두 탐색
            while (d < 8)
            {
                // 다음 이동할 위치 (g, h) 계산
                int g = i + moves[d].a;
                int h = j + moves[d].b;

                // 출구에 도달한 경우 (g == m && h == p)
                if ((g == m) && (h == p))
                {
                    // 경로 출력 및 함수 종료
                    mark[g][h] = 2;
                    mark[i][j] = 2;
                    cout << "the term near the exit: " << i << " " << j << endl;
                    cout << "exit: " << m << " " << p << endl;
                    maze[i][j] = 2;
                    maze[g][h] = 2;
                    return;
                }

                // 이동할 수 있는 새로운 위치인 경우 (길이 있고, 방문한 적 없음)
                if ((maze[g][h] == 0) && (mark[g][h] == 0))
                {
                    mark[g][h] = 1; // 새로운 위치를 방문했다고 표시

                    // 현재 위치와 다음 탐색할 방향을 스택에 저장
                    // d방향의 이웃은 이미 확인했으므로 d+1 부터 탐색
                    temp.x = i;
                    temp.y = j;
                    temp.dir = d + 1;
                    st.push(temp);

                    // 현재 위치를 경로의 일부로 표시
                    mark[i][j] = 2;
                    maze[i][j] = 2;

                    // (g, h)로 이동하고, 방향은 처음(N)부터 다시 탐색
                    i = g;
                    j = h;
                    d = N;
                }
                // 이동할 수 없는 경우, 다음 방향 시도
                else
                {
                    d++;
                }
            } // end of inner while loop

            // 8방향 모두 탐색했지만 길이 없을 때, 현재 위치의 마크와 미로 값을 다시 초기화 (백트래킹)
            mark[i][j] = 0;
            maze[i][j] = 0;

        } // end of outer while loop

        // 스택이 모두 비워질 때까지 출구를 찾지 못한 경우
        cout << "no path in maze " << endl;
    }
}
```

### 3.1 첫 번째 코드의 동작 흐름

**Step 1: 초기화**
- 시작점 (1, 1)을 mark로 표시: `mark[1][1] = 1`
- 시작 위치, 방향과 함께 스택에 저장
- 방향은 E(동쪽)부터 시작

**Step 2: 외부 while 루프**
```cpp
while (!st.empty())
```
스택이 비어있지 않는 한 계속 반복합니다.

**Step 3: 스택에서 꺼내기**
```cpp
temp = st.top();
st.pop();
int i = temp.x;
int j = temp.y;
int d = temp.dir;
```
스택에서 위치 정보를 꺼냅니다.

**Step 4: 현재 위치 초기화** (첫 번째 코드의 특징)
```cpp
mark[i][j] = 0;
maze[i][j] = 0;
```
스택에서 꺼낸 직후 즉시 이 위치를 초기화합니다.

**Step 5: 내부 while 루프 - 8방향 탐색**
```cpp
while (d < 8)
```
현재 위치에서 d 방향부터 8방향까지 탐색합니다.

**Step 6: 다음 위치 계산**
```cpp
int g = i + moves[d].a;
int h = j + moves[d].b;
```
moves 배열을 사용하여 d 방향의 다음 좌표를 계산합니다.

**Step 7: 출구 도달 확인**
```cpp
if ((g == m) && (h == p))
{
    mark[g][h] = 2;
    mark[i][j] = 2;
    cout << "the term near the exit: " << i << " " << j << endl;
    cout << "exit: " << m << " " << p << endl;
    maze[i][j] = 2;
    maze[g][h] = 2;
    return;
}
```
만약 다음 위치가 출구라면 성공입니다. 현재 위치와 출구를 경로로 표시하고 함수를 종료합니다.

**Step 8: 갈 수 있는 길 확인**
```cpp
if ((maze[g][h] == 0) && (mark[g][h] == 0))
```
미로에서 길이 있고(`maze[g][h] == 0`) AND 방문한 적이 없으면(`mark[g][h] == 0`), 이 위치로 이동할 수 있습니다.

**Step 9: 새로운 위치로 이동 준비**
```cpp
mark[g][h] = 1; // 새로운 위치를 방문했다고 표시

// 현재 위치와 다음 탐색할 방향을 스택에 저장
temp.x = i;
temp.y = j;
temp.dir = d + 1;
st.push(temp);

// 현재 위치를 경로의 일부로 표시
mark[i][j] = 2;
maze[i][j] = 2;

// (g, h)로 이동하고, 방향은 처음(N)부터 다시 탐색
i = g;
j = h;
d = N;
```

- 새로운 위치(g, h)를 방문했다고 표시
- 현재 위치(i, j)와 다음 시도할 방향(d+1)을 스택에 저장
- 현재 위치를 경로로 표시
- 새로운 위치로 실제 이동
- 방향을 처음(N)부터 다시 설정

**Step 10: 갈 수 없는 경우**
```cpp
else
{
    d++;
}
```
이 방향으로 갈 수 없으면 다음 방향을 시도합니다.

**Step 11: 백트래킹 - 내부 while 루프 종료**
```cpp
// 8방향 모두 탐색했지만 길이 없을 때, 현재 위치의 마크와 미로 값을 다시 초기화 (백트래킹)
mark[i][j] = 0;
maze[i][j] = 0;
```
내부 while 루프가 끝나면 (d >= 8), 현재 위치가 모든 방향으로 막혀있다는 뜻입니다. 따라서 이 위치를 초기화해서 방문하지 않은 상태로 돌려놓습니다. 이것이 **백트래킹**입니다.

**Step 12: 스택에서 자동으로 이전 위치 꺼냄**
외부 while 루프가 다시 반복되면서 스택에서 다음 항목(이전에 저장한 위치와 방향)을 꺼냅니다.

### 3.2 첫 번째 코드의 마크 상태 표현

- `mark[i][j] = 0`: 방문하지 않은 위치
- `mark[i][j] = 1`: 현재 탐색 중인 위치 (스택에 저장됨)
- `mark[i][j] = 2`: 최종 경로의 일부

### 3.3 첫 번째 코드의 문제점

#### 문제 1: 스택에서 꺼낼 때 즉시 초기화

```cpp
while (!st.empty()) {
    temp = st.top();
    st.pop();
    int i = temp.x;
    int j = temp.y;
    int d = temp.dir;
    
    // ❌ 버그 1: 스택에서 꺼낸 직후 즉시 초기화
    mark[i][j] = 0;
    maze[i][j] = 0;
```

**문제의 상황:**
- 위치 A에서 위치 B로 이동 (B를 경로로 표시: `mark[B] = 2`)
- 위치 B에서 모든 방향이 막힘
- **스택에 (A, 다음방향)이 저장되어 있음**
- 스택에서 (A, 다음방향)을 꺼냄
- 그 순간 `mark[A] = 0`으로 초기화 ← **문제!**
- 하지만 `i`는 아직 B를 가리킴 (아직 A로 돌아가지 않음)

#### 문제 2: 경로 표시 후 위치 변경

```cpp
// 현재 위치를 경로의 일부로 표시
mark[i][j] = 2;
maze[i][j] = 2;

// (g, h)로 이동하고, 방향은 처음(N)부터 다시 탐색
i = g;
j = h;
d = N;
```

**문제:**
- 현재 위치(i, j)를 경로로 표시
- 그 다음에 위치를 변경
- while 루프가 다시 돌 때, `i`와 `j`가 이미 새로운 위치 `(g, h)`로 변경됨
- while 루프가 끝나면?
  ```cpp
  // while 루프가 끝남 (d >= 8)
  mark[i][j] = 0;  // ← 이 i, j는 이미 변경된 값!
  ```

실제로는 작동하지만, **의도가 불명확**합니다.

#### 문제 3: 마크를 두 번 초기화

**백트래킹 흐름:**

```
스택에 (A, 다음방향) 저장
    ↓
B에서 모든 방향이 막힘
    ↓
while 루프 종료
    ↓
mark[B] = 0  ← 백트래킹 (맞음)
    ↓
스택에서 (A, 다음방향) 꺼냄
    ↓
mark[A] = 0  ← 다시 초기화? (불필요!)
```

마크를 불필요하게 두 번 초기화하므로 **효율성이 낮고**, **코드의 의도가 불명확**합니다.

## 4. 두 번째 코드 상세 분석

```cpp
void findPath(int m, int p) {
    try {
        std::stack<items> st;

        // 1. 출발점 (1,1), 이동 방향 dir = 2(동쪽)을 스택에 push
        items temp;
        temp.x = 1;
        temp.y = 1;
        temp.dir = E; // E는 2
        st.push(temp);

        // 2. while (stack is not empty)
        while (!st.empty()) 
        {
            temp = st.top();
            st.pop(); // unstack
            int i = temp.x;
            int j = temp.y;
            int d = temp.dir;

            // 4. while (there are more moves)
            while (d < 8) // 8방향 탐색
            {
                // 5. (g,h) = 다음 이동 좌표 계산
                int g = i + moves[d].a;
                int h = j + moves[d].b;

                // 6. if ((g == m) && (h == p)) { success; }
                if ((g == m) && (h == p)) {
                    // 성공: 현재 위치(i,j)와 도착점(g,h)을 경로로 표시
                    mark[g][h] = 2;
                    mark[i][j] = 2;
                    cout << "the term near the exit: " << i << " " << j << endl;
                    cout << "exit: " << m << " " << p << endl;
                    return;
                }

                // 7. if (갈 수 있는 길이고 && 아직 방문 안 했으면)
                if ((maze[g][h] == 0) && (mark[g][h] == 0)) { // new position

                    // 7-1. mark[g][h] = 1; (방문 표시)
                    mark[g][h] = 1;

                    //push the old temp to the stack, but the direction changes.
                    //Because the neighbor in the direction of d has been checked.
                    // 7-2. 현재 위치(i,j)와 다음 시도할 방향(d+1)을 스택에 push
                    temp.x = i;
                    temp.y = j;
                    temp.dir = d + 1;
                    st.push(temp); // stack it

                    // 7-3. 새로운 위치로 이동하고, 방향은 처음(N)부터 다시 탐색
                    i = g;
                    j = h;
                    d = N; // moves to (g,h)
                }
                // 8. else d++; (다음 방향 시도)
                else {
                    d++; // try next direction
                }
            }
        }
        cout << "no path in maze " << endl;
    }
}
```

### 4.1 두 번째 코드의 동작 흐름

**Step 1: 초기화**
- 시작 위치(1, 1)와 방향 E(동쪽)을 스택에 저장

**Step 2: 외부 while 루프**
```cpp
while (!st.empty()) 
```
스택이 비어있지 않는 한 계속 반복합니다.

**Step 3: 스택에서 꺼내기**
```cpp
temp = st.top();
st.pop();
int i = temp.x;
int j = temp.y;
int d = temp.dir;
```
스택에서 위치 정보를 꺼냅니다.

**Step 4: 초기화하지 않음** (두 번째 코드의 특징)
```cpp
// ✅ 초기화하지 않음!
// 바로 8방향 탐색으로 진행
```

**Step 5: 내부 while 루프 - 8방향 탐색**
```cpp
while (d < 8) // 8방향 탐색
```

**Step 6: 다음 위치 계산**
```cpp
int g = i + moves[d].a;
int h = j + moves[d].b;
```

**Step 7: 출구 도달 확인**
```cpp

```
다음 위치가 출구라면 성공입니다.

**Step 8: 갈 수 있는 길 확인**
```cpp

    mark[g][h] = 1;
```

**Step 10: 백트래킹 - 내부 while 루프 종료** (두 번째 코드의 특징)
내부 while 루프가 끝나면, 백트래킹이 자동으로 일어납니다:
```cpp
// while 루프가 끝남 (d >= 8)
// 특별히 mark를 초기화하지 않음
// 스택이 이미 자동으로 처리함
```

실제로는 mark를 초기화할 필요가 없습니다. 왜냐하면:
- 스택에 이미 이전 위치가 저장되어 있음
- 외부 while 루프가 다시 반복되면서 스택에서 이전 위치를 꺼냄
- 새로운 위치에서 다른 방향을 시도할 수 있음

### 4.2 두 번째 코드가 올바른 이유

**1. 명확한 로직:**
- 스택에서 꺼낼 때 즉시 초기화하지 않음
- 내부 while 루프가 끝난 후에만 관련된 처리가 끝남
- 코드의 의도가 분명함

**2. 효율성:**
- 불필요한 초기화가 없음
- 마크를 한 번만 관리함

**3. 명확한 백트래킹:**
- 백트래킹이 명시적으로 일어나는 시점이 명확함
- 8방향 모두 탐색했는데 갈 곳이 없으면, while 루프가 끝남
- 스택에서 이전 위치를 꺼냄 (자동 백트래킹)

## 7. 종합 정리 및 결론

### 7.1 두 코드 모두 백트래킹인가?

**답: 네, 두 코드 모두 백트래킹을 구현하고 있습니다.**

하지만 구현 방식과 효율성이 다릅니다.

### 7.2 어느 코드가 더 정확한가?

**답: 두 번째 코드가 더 정확하고 효율적입니다.**

**이유:**
- 첫 번째 코드는 마크를 불필요하게 두 번 초기화
- 첫 번째 코드는 경로를 표시하므로 불필요한 연산 추가
- 첫 번째 코드는 의도가 불명확하여 유지보수 어려움
- 두 번째 코드는 명확한 로직으로 버그 가능성 낮음
- 두 번째 코드는 더 간단하고 효율적

### 7.3 백트래킹의 본질

백트래킹의 본질은 **`mark[i][j] = 0`** 부분입니다.

이것이 의미하는 바:
- "이 길은 막혔으니까 다시 미방문 상태로 돌려놓자"
- 이전 위치로 돌아갈 수 있게 준비
- 다른 경로를 시도할 수 있도록 함

### 7.4 마크(mark) 배열의 상태 의미

```
mark[i][j] = 0: 방문하지 않은 위치 (갈 수 있음)
mark[i][j] = 1: 현재 탐색 중인 위치 (스택에 저장됨)
mark[i][j] = 2: 최종 경로의 일부 (또는 현재 경로)
```

### 7.5 미로(maze) 배열의 상태 의미

```
maze[i][j] = 0: 길이 있는 위치 (갈 수 있음)
maze[i][j] = 1: 벽인 위치 (갈 수 없음)
maze[i][j] = 2: 경로의 일부 (최종 결과 표시용)
```

### 7.6 스택의 역할

스택은 **이전 위치와 시도할 방향을 저장**하는 역할입니다.

```cpp
temp.x = i;           // 현재 위치 x
temp.y = j;           // 현재 위치 y
temp.dir = d + 1;     // 다음에 시도할 방향
st.push(temp);        // 스택에 저장
```

이렇게 저장된 정보로:
1. **새로운 위치로 이동 가능** (i, j로 이동)
2. **나중에 돌아올 수 있음** (스택에서 꺼낼 때)
3. **다른 방향을 시도할 수 있음** (d+1 방향부터)

### 7.7 8방향 탐색

```cpp
// moves 배열 예시 (일반적인 방향 정의)
// N(0): 북쪽, NE(1): 북동쪽, E(2): 동쪽, ...
while (d < 8)  // d = 0부터 7까지, 총 8방향
```

8방향의 일반적인 정의:
```
0(N)  1(NE) 2(E)
7(NW)       3(SE)
6(SW) 5(SE) 4(S)
```

### 7.8 첫 번째 코드의 불필요한 부분

```cpp
// 불필요한 부분 1: 스택에서 꺼낼 때 즉시 초기화
mark[i][j] = 0;
maze[i][j] = 0;

// ... 중간 코드 ...

// 불필요한 부분 2: while 루프 끝난 후 다시 초기화
mark[i][j] = 0;
maze[i][j] = 0;

// 불필요한 부분 3: 경로를 표시하는 과정
mark[i][j] = 2;
maze[i][j] = 2;
```

이 부분들이 제거되어도 백트래킹은 정상 작동합니다.

## 8. 알고리즘 동작 원리 깊이 있게 이해하기

### 8.1 왜 스택을 사용하는가?

스택을 사용하는 이유는 **LIFO(Last In First Out)** 특성 때문입니다.

```
A → B → C (길이 막힘)
↑ 돌아가기 ↓
C에서 스택에 B 저장
B에서 스택에 A 저장
...
C에서 막혔을 때 스택에서 B를 꺼냄
B에서 막혔을 때 스택에서 A를 꺼냄
```

이렇게 하면 **자동으로 가장 최근의 위치로 돌아갑니다.**

### 8.2 왜 방향을 저장해야 하는가?

방향을 저장하는 이유는 **이미 확인한 방향을 다시 시도하지 않기 위함**입니다.

```cpp
temp.dir = d + 1;  // ← 중요!
```

예를 들어:
- A에서 동쪽(d=2)으로 B를 발견
- B로 이동하기 전에 스택에 (A, d+1=3) 저장
- 나중에 이 위치로 돌아오면 동쪽(d=2)은 이미 확인했으므로 남동쪽(d=3)부터 시작
- **중복 탐색 방지**

### 8.3 왜 d = N으로 초기화하는가?

새로운 위치로 이동할 때 d = N으로 설정하는 이유:

```cpp
i = g;
j = h;
d = N;  // ← 처음부터 다시 탐색
```

새로운 위치에서는 **모든 방향을 다시 탐색**해야 하기 때문입니다.

이전 위치에서 동쪽으로 왔다고 해서, 새로운 위치에서 동쪽으로 갈 수 있다는 보장이 없습니다.

### 8.4 mark와 maze를 구분하는 이유

**maze 배열:**
- 미로의 고정된 구조
- 0 = 길, 1 = 벽
- 한 번 설정되면 바뀌지 않음

**mark 배열:**
- 탐색 과정에서의 상태
- 0 = 미방문, 1 = 탐색 중, 2 = 경로
- 동적으로 변함

분리하는 이유:
- 원본 미로 구조 보존
- 여러 번 탐색 가능
- 경로 추적 용이

### 8.5 왜 (g==m) && (h==p) 조건이 필요한가?

```cpp
if ((g == m) && (h == p)) {
    // 출구 도달!
    return;
}
```

이 조건은 **출구에 도달했는지 확인**하는 것입니다.

- m, p = 출구의 좌표
- g, h = 다음 이동할 위치의 좌표
- 다음 위치가 정확히 출구라면 성공!

- mark[1][1] = 1


**Step 2: (1,1)에서 동쪽 탐색**

```
mark[1][1] = 2; maze[1][1] = 2;
```

```
(1,2)에서 동쪽: 길
...계속...
```

**Step 4: 막다른 곳에 도달**
```
(어떤 위치)에서 8방향 모두 갈 수 없음
while 루프 종료
mark[(해당위치)] = 0; maze[(해당위치)] = 0;
백트래킹!
```

**동일한 흐름이지만 더 간단:**
- 스택에서 꺼낼 때 초기화 안 함
- 경로 표시 안 함
- 코드가 더 깔끔함

## 10. 실제 사용 시 권장사항

### 10.1 어떤 코드를 사용할 것인가?

**권장: 두 번째 코드**

**이유:**
1. 더 간단하고 명확함

### 10.2 면접 또는 시험에서

면접이나 시험에서 백트래킹 알고리즘을 설명할 때:

1. **기본 개념 설명:**
   - "막다른 길에서 이전 위치로 돌아가는 알고리즘입니다"
   - "스택을 사용해서 이전 위치를 저장합니다"

2. **핵심 코드 설명:**
   - "mark를 0으로 초기화하는 것이 백트래킹입니다"
   - "스택에서 이전 위치를 꺼내면 자동으로 돌아갑니다"

3. **코드 작성 시:**
   - 두 번째 코드 스타일을 따르는 것이 좋음
   - 더 깔끔하고 이해하기 쉬움

### 10.3 개선 방안

두 코드를 더 개선할 수 있는 방법:

```cpp
// 개선된 버전
void findPath(int m, int p) {
    std::stack<items> st;
    
    items start;
    start.x = 1;
    start.y = 1;
    start.dir = N;
    st.push(start);
    
    mark[1][1] = 1;
    
    while (!st.empty()) {
        items current = st.top();
        st.pop();
        int x = current.x;
        int y = current.y;
        int dir = current.dir;
        
        while (dir < 8) {
            int nx = x + moves[dir].a;
            int ny = y + moves[dir].b;
            
            // 출구 도달
            if (nx == m && ny == p) {
                cout << "경로 발견!" << endl;
                return;
            }
            
            // 갈 수 있는 길
            if (maze[nx][ny] == 0 && mark[nx][ny] == 0) {
                mark[nx][ny] = 1;
                
                items next;
                next.x = x;
                next.y = y;
                next.dir = dir + 1;
                st.push(next);
                
                x = nx;
                y = ny;
                dir = N;
            } else {
                dir++;
            }
        }
    }
    
    cout << "경로 없음" << endl;
}
```

## 11. 자주 하는 실수 및 주의사항

### 11.1 자주 하는 실수

**실수 1: mark 배열을 초기화하지 않음**
```cpp
// ❌ 잘못된 예
if (maze[g][h] == 0 && mark[g][h] == 0) {
    // mark[g][h] = 1; ← 빼먹음!
    st.push(temp);
}
```

이렇게 하면 **같은 위치를 여러 번 방문**할 수 있습니다.

**실수 2: 백트래킹을 하지 않음**
```cpp
// ❌ 잘못된 예
while (d < 8) {
    // ... 탐색 ...
}
// mark[i][j] = 0; ← 백트래킹 빼먹음!
```

이렇게 하면 **경로를 찾지 못할 수 있습니다.**

**실수 3: 스택에 잘못된 정보 저장**
```cpp
// ❌ 잘못된 예
temp.x = i;
temp.y = j;
temp.dir = d;  // ← d+1이 아니라 d!
st.push(temp);
```

이렇게 하면 **같은 방향을 계속 확인**하게 됩니다.

### 11.2 주의사항

1. **초기화 순서:** 위치 정보를 먼저 꺼낸 후 처리
2. **방향 관리:** d+1로 다음 방향을 저장
3. **마크 관리:** mark를 일관되게 유지
4. **출구 확인:** 올바른 출구 좌표 확인

## 12. 최종 정리

### 12.1 요약

**백트래킹의 정의:**
미로를 탐색하다가 막다른 길에 도달했을 때, 이전 위치로 돌아가서 다른 경로를 시도하는 알고리즘입니다.

**백트래킹의 3요소:**
1. 탐색 (while 루프로 8방향 확인)

3. 철회 (mark를 0으로 초기화)

**두 코드의 차이:**
- 첫 번째: 불필요한 초기화 2회 + 경로 표시
- 두 번째: 필요한 작업만 수행 (더 효율적)

**권장:**
- 두 번째 코드 사용
- 간단하고 명확하고 효율적
