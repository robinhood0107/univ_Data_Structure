# 스택으로 하는 백트래킹 - 간단 설명

## 1. 백트래킹이란?

길이 막히면 **돌아가서 다른 길을 시도**하는 것입니다.

```
A → B → C (막혔다!)
↓ 돌아가기
A에서 다른 방향 시도
```

---

## 2. 스택으로 구현하는 방법

### 핵심 아이디어
- **스택에 이전 위치를 저장**해두기
- 길이 막히면 스택에서 꺼내서 돌아가기

### 3가지 핵심 코드

#### 1) 갈 수 있는 길을 찾았을 때
```cpp
if ((maze[g][h] == 0) && (mark[g][h] == 0)) {  // 길이 있고 방문 안 함
    mark[g][h] = 1;                // 방문 표시
    
    temp.x = i;
    temp.y = j;
    temp.dir = d + 1;              // 다음 방향부터 시도하도록
    st.push(temp);                 // 이전 위치를 스택에 저장
    
    i = g;
    j = h;
    d = N;                         // 새 위치에서 처음부터 탐색
}
```

**무엇을 저장하는가?**
- `i, j`: 현재 위치 (나중에 돌아올 곳)
- `d + 1`: 다음에 시도할 방향 (이미 확인한 방향은 다시 안 함)

#### 2) 갈 수 없는 경우
```cpp
else {
    d++;  // 다음 방향 시도
}
```

#### 3) 8방향 다 막혔을 때 (백트래킹 발생!)
```cpp
while (d < 8) {  // 8방향 모두 확인
    // ... 코드 ...
}
// 여기 나왔다는 것 = 8방향 모두 갈 수 없다 = 백트래킹!

mark[i][j] = 0;   // 이 위치를 "미방문"으로 돌려놓기
maze[i][j] = 0;

// 스택에서 자동으로 이전 위치 꺼냐기
// (다음 루프에서 while(!st.empty()) 계속 반복)
```

## 3. 전체 구조

```cpp
void findPath(int m, int p) {
    std::stack<items> st;
    
    // 1. 시작점을 스택에 저장
    items temp;
    temp.x = 1;
    temp.y = 1;
    temp.dir = N;
    st.push(temp);
    mark[1][1] = 1;
    
    // 2. 스택이 비울 때까지 계속
    while (!st.empty()) {
        // 스택에서 꺼내기
        temp = st.top();
        st.pop();
        int i = temp.x;
        int j = temp.y;
        int d = temp.dir;
        
        // 3. 8방향 탐색
        while (d < 8) {
            int g = i + moves[d].a;
            int h = j + moves[d].b;
            
            // 출구 찾음
            if ((g == m) && (h == p)) {
                mark[g][h] = 2;
                mark[i][j] = 2;
                cout << "찾음!" << endl;
                return;
            }
            
            // 갈 수 있는 길
            if ((maze[g][h] == 0) && (mark[g][h] == 0)) {
                mark[g][h] = 1;
                
                temp.x = i;
                temp.y = j;
                temp.dir = d + 1;
                st.push(temp);        // ← 이전 위치 저장!
                
                i = g;
                j = h;
                d = N;
            }
            // 갈 수 없음
            else {
                d++;
            }
        }
        
        // 8방향 다 막혔을 때 (백트래킹)
        mark[i][j] = 0;
        maze[i][j] = 0;
    }
    
    cout << "경로 없음" << endl;
}
```

## 4. 동작 흐름 (그림으로 이해)

```
위치 A에서 동쪽으로 갈 수 있음
    ↓
스택에 (A, 동쪽 다음 방향) 저장  ← 나중에 A로 돌아올 준비
    ↓
위치 B로 이동
    ↓
B에서 8방향 모두 막힘
    ↓
mark[B] = 0 (B를 미방문으로 돌려놈)
    ↓
스택에서 (A, 동쪽 다음 방향) 꺼냄  ← 자동으로 A로 돌아감!
    ↓
A에서 다음 방향 시도
```

---

## 5. 핵심만 기억하기

| 상황 | 코드 | 의미 |
|------|------|------|
| 갈 수 있는 길 | `st.push(temp)` | 이전 위치 저장 (나중에 돌아올 곳) |
| 길이 막힘 | `d++` | 다음 방향 시도 |
| 8방향 다 막힘 | `mark[i][j] = 0` | 백트래킹 (이 위치 포기) |
| 스택 비움 | `while (!st.empty())` | 계속 탐색 |

---

## 6. 가장 중요한 부분

**`st.push(temp)` 이 한 줄이 핵심입니다!**

이것이 없으면 길이 막혔을 때 **어디로 돌아가야 할지 몰라집니다.**

스택에 **이전 위치와 방향**을 저장해야만:
- 새로운 위치에서 계속 탐색할 수 있음
- 길이 막히면 자동으로 이전 위치로 돌아갈 수 있음
- 다른 방향을 시도할 수 있음
