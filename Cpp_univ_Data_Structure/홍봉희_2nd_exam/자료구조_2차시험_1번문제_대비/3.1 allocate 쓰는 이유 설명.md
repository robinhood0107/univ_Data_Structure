# 📝 C++ 메모리 해제(delete) 핵심 원리 요약

### 1. `delete p;` 와 `::operator delete(p);` 의 차이

일상적으로 사용하는 `delete p;`는 **두 가지 작업**을 순서대로 수행하는 **표현식(Expression)**입니다.

1.  **소멸자 호출**: `p`가 가리키는 객체의 소멸자(`~ClassName()`)를 호출하여 객체 내부의 리소스를 먼저 정리합니다.
2.  **메모리 해제**: 그 후 `operator delete()` 함수를 호출하여 객체가 차지하던 순수 메모리 공간을 시스템에 반환합니다.

반면, `::operator delete(p);`는 위 과정 중 **2번(메모리 해제)만** 직접 수행하는 **함수 호출(Function Call)**입니다.

* `::`: **전역(Global) 범위**를 의미하는 연산자입니다.
* `operator delete`: 메모리 해제만 담당하는 **함수의 이름**입니다.

> **⚠️ 중요**: `::operator delete(p);`를 직접 호출하면 객체의 **소멸자가 실행되지 않으므로**, 일반적인 상황에서는 절대로 사용해서는 안 됩니다. 리소스 누수의 원인이 됩니다. `placement new`와 같은 특수한 고급 기법에서만 사용됩니다.

---

### 2. `operator` 키워드의 역할

`operator` 키워드는 컴파일러에게 "지금부터 정의하는 것은 일반 함수가 아니라, 특정 **연산자**의 작동 방식입니다"라고 알려주는 **신호**입니다.

* **연산자 오버로딩**: 사용자가 만든 클래스(e.g., `Vector2D`)가 `+`, `-` 같은 내장 연산자를 사용할 수 있도록 그 기능을 새롭게 정의할 때 사용합니다. (e.g., `Vector2D operator+(...)`)
* **특별 함수 명시**: `new`, `delete`처럼 시스템의 동작과 깊게 연관된 특별한 함수의 기능을 재정의할 때 사용합니다. (e.g., `operator new`, `operator delete`)
* **문법적 구분**: `+`나 `new` 같은 키워드는 일반 함수 이름으로 쓸 수 없기 때문에, `operator`를 붙여 문법적 모호성을 해결하고 "이것은 연산자 정의다"라고 명확히 구분합니다.

---

### 3. `delete`가 호출하는 대상

`delete p;`를 실행할 때, 소멸자가 호출되는 대상은 **포인터 `p`가 가리키는 바로 그 객체**입니다.

컴파일러는 포인터 변수를 선언할 때 **해당 포인터의 타입**(`Dog*`, `Car*` 등)을 정확히 기억하고 있습니다. 이 타입 정보를 바탕으로 `delete`가 호출되면 해당 클래스의 소멸자를 정확히 찾아 실행할 수 있습니다.
