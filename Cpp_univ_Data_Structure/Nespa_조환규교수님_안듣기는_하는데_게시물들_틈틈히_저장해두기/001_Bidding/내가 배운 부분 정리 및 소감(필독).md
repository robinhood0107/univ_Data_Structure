
## 1. map은 기본적으로 key를 오름차순으로 정렬한다.

## 2. map에서 key를 내림차순으로 정리한 상태를 만들고 싶다면, `3번째 인자`에 `greater<>`를 적어야 한다.
```cpp
map<int, vector<string>,greater<int>> mymap;
```

#### 추가 설명

map이나 set이나 이 트리tree 자료구조형은 템플릿이다.
```cpp   
    template <
        class Key,
        class compare = std::less<Key>
        class Allocator = std::allocator<Key>
        > class set;
    //이런 방식으로 set이 이루어져있다. map도 마찬가지
```
##### 템플릿구조 내부에 compare 클래스를 가지는데, 여기에 less<>함수를 사용한다. 
##### 여기서 less<>함수를 greater<>로 변경하는 방법이 바로 3번째 인자로 greater<>를 주는 것
##### 이렇게 3번째 인자로 클래스가 사용하고 있는 정책을 템플릿인자로 전달해 변환하는 방식을 단위전략 디자인 (Policy Base Design)이라고 말한다.
    
## 3."정렬해야 하는데 중복은 제외해야 한다는 조건"이 나오면 map을 반드시 쓰자. 
#### 중복되는 것을 싹 묶어서 처리해버릴 수 있다!!! 
#### `map<int, vector<string>, greater<int>> mymap;` 이렇게 vector에 중복값을 `mymap[price].push_back(n);`으로 넣어버릴 수 있다.
